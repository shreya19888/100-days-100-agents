# Overview

DataPilot AI is an enterprise data catalog and onboarding platform designed to help engineers discover, understand, and learn enterprise datasets.

Instead of searching across multiple documentation portals, users can explore datasets, understand ownership, view lineage, learn SQL patterns, and access guided learning resources from a single application.

# Getting Started

Clone the repository

```bash
git clone https://github.com/shreya19888/100-days-100-agents.git
```

Navigate to the project

```bash
cd 100-days-100-agents/day-005-datapilot-ai
```

Install dependencies

```bash
npm install
```

Create an environment file

```text
OPENAI_API_KEY=your_api_key_here
```

Run locally

```bash
npm run dev
```

Open

```
http://localhost:3000
```
