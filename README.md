# 🚀 100 Days • 100 AI Agents

Building one production-ready AI agent every day.

## Goal

Build **100 practical AI agents** that solve real-world problems across healthcare, HR, climate, data, social good, enterprise AI, and beyond.

The goal isn't simply to build 100 AI demos.

It's to learn by shipping — taking an idea from **problem → architecture → AI → product → deployment**.
